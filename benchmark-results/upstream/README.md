# Upstream benchmark artifacts

These `webwild-*` and `tiny-genimage-*` files are inherited from the
Proofmark codebase RealImage forked from (see `NOTICE.md`). They document
the upstream project's own benchmark history and are retained only so the
regression scripts that reference them (`scripts/audit-baseline-bias.mjs`,
`scripts/audit-fast-path.mjs`, `scripts/audit-holdout.mjs`) keep working.
They are not RealImage's own accuracy claims — see `BENCHMARK.md` and
`MODEL_CARD.md` for RealImage's own holdout results.
